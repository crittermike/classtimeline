# Class Timeline

A live daily schedule board for classroom smart boards.

Shows the day as a proportional vertical timeline, highlights the current
activity with a countdown, checks off what's done, and previews what's next.
Everything is editable inline — drag to move or resize a block, lock the
blocks that never move, and adjust a single day without touching the weekly
schedule.

Optional cloud sync keeps the same schedule on every device in the room.

**Live:** https://crittermike.github.io/classtimeline/

Zero build step. The whole app is one `index.html`.
